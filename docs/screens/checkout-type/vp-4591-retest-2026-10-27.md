# Re-test Checkout Type Setting — POS Windows (27/10/2026)

Re-test toàn bộ CHK-POS-001 → 038 của [VP-4591](https://linear.app/fastboy/issue/VP-4591/pos-checkout-type-setting-windows-android)
([test cases](checkout-type-test-cases.md) · [spec](../../specs/checkout-type-setting.md)).
Lần này **mọi order đều tạo từ check-in GoCheckin trên GAP kiosk** (`gap.gocheckin.net` → GoCheckin, iframe `/iframe`),
không tạo bằng Quick Checkout trên POS (trừ CHK-POS-033). Điều khiển app Volt POS đang cài qua WebView2 remote debugging,
đổi setting trên Portal DEV, đối chiếu điểm trên màn hình khách + số dư điểm của khách trên server.

Kết quả gốc + ảnh: comment Linear VP-4591 ngày 27/10/2026. Bug mở: [VP-5151](https://linear.app/fastboy/issue/VP-5151).
