## Coverage map

| Acceptance criterion / Requirement                                        | Test case        |
| ------------------------------------------------------------------------- | ---------------- |
| POS allows Gift Card sale while offline                                   | TC 1, TC 2       |
| Offline Gift Card orders only allow Cash payment                          | TC 1, TC 3       |
| POS blocks all non-cash payment methods                                   | TC 3             |
| Offline Gift Card sale creates local pending sync transaction             | TC 5             |
| Gift Card not activated/reloaded immediately while offline                | TC 1, TC 2, TC 5 |
| POS automatically syncs pending transactions when network returns         | TC 6             |
| Giao dịch pending retry & không double-activate khi sync gián đoạn        | TC 7             |
| Server activates/reloads Gift Card only after successful validation       | TC 8             |
| POS refreshes/checks Gift Card balance after successful sync & activation | TC 8             |
| POS displays warning before completing offline Gift Card order            | TC 9             |
| Thông tin gift card lưu encrypted (main flow #2)                          | TC 4             |
| Nhiều giao dịch pending sync đầy đủ & không trùng lặp khi mạng trở lại    | TC 10            |

> **Chưa cover (gợi ý mở rộng nếu cần > 10 TC):** sync conflict do server-side khi cùng Gift Card bị 2 POS cập nhật song song, và xử lý khi server trả validation fail cho Gift Card đã hết hạn — nên tách TC riêng nếu muốn nghiệm thu đầy đủ.
