# VP-2465 — Improve Display: More Characters for Service Names on Create Order Screen — Test Cases

> Nguồn: Linear ticket [VP-2465](https://linear.app/fastboy/issue/VP-2465/pos-improve-display-more-characters-for-service-names-on-the-create) (mô tả + Acceptance Criteria). Ngôn ngữ: Tiếng Việt (theo nguồn). Related: VP-2393.
>
> ⚠️ **Điểm cần xác nhận trước khi test:**
>
> 1. "28 ký tự" — không rõ đây là spec cứng (đếm chính xác 28 ký tự) hay chỉ là ước lượng cho line-clamp 2 dòng (vì độ rộng ký tự tiếng Việt có dấu không đều, line-clamp theo CSS hoạt động theo pixel-width chứ không theo số ký tự). Các TC dưới đây test theo hành vi quan sát được (2 dòng + `...` ở dòng 3), có TC riêng để đo số ký tự hiển thị thực tế.
> 2. "Dấu `...` hiển thị ở dòng thứ 3" — cần xác nhận dòng 3 có luôn tồn tại/chiếm chỗ hay chỉ xuất hiện khi tên bị cắt (ảnh hưởng đến yêu cầu "không đổi kích thước tổng thể card").
