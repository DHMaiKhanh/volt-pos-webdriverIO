# VP-1343 — Count Days Off Validation — Staff Income Calculation — Test Cases

> **Nguồn:** Linear ticket VP-1343 (description + acceptance criteria) + UI Compensation tab (ảnh). **Ngôn ngữ:** Tiếng Việt. **Format:** Excel-style single table.
> **Phạm vi:** Tập trung phần **tính lương / Staff Income** — cách `violation` flag (từ rule Count Days Off) quyết định payroll trả `Salary only` hay `MAX(Salary, Commission)` cho staff `Commission + Salary`. Logic Settings UI & engine attendance chỉ test ở mức ảnh hưởng tới income.
> **Quy ước công thức:** `violation=false → Income = MAX(Salary, Commission)`; `violation=true → Income = Salary only` (kể cả khi Commission cao hơn). Dữ liệu mẫu theo ảnh: Compensation = `Commission + Salary`, Wage Per Day = $100, Commission For Service = Staff 50%, `Limit days off` = ON, `Max days off allowed` = 1, `Days not allowed to be off` = Tue, Wed.
> ⚠️ **Open question (chưa chốt business):** _Approved Leave (nghỉ phép đã duyệt)_ có tính vào Day Off không → ảnh hưởng trực tiếp tới violation và income. Xem TC19. Cần xác nhận trước khi chốt Pass/Fail.
> ⚠️ **Dependency:** Income cuối cùng do consumer VP-1341 (Salary formula) tính; TC ở đây verify nhánh chọn (Salary vs MAX) đúng theo flag, và giá trị Salary/Commission tính đúng.
