> ⚠️ **Mâu thuẫn phát hiện (tham chiếu trong NOTE bằng MT-n):**
>
> 1. **MT-1 — Action trên trang:** VP-1198 (Done) ghi rõ trang **read-only**: chỉ **View Detail**, Device History chỉ log sự kiện hệ thống, permission chỉ cần "view device data". Doc Device Management (cập nhật 2026-06-11) và file ticket thêm **Remote View**, **Disconnect**, **Credential update** và audit log action của user. Không thấy ticket nào ship các action này → các TC Remote View/Disconnect/Credential giữ lại, nếu Portal production chưa có nút thì ghi STATUS = Skip.
> 2. **MT-2 — Chu kỳ cập nhật:** Doc ghi trạng thái cập nhật "~mỗi giờ" (Merchant Overview cũng ghi Device Summary sync 1 giờ). Code POS production gửi heartbeat `/devices/healthz` mỗi **5 phút**, server coi **Offline nếu không thấy trong 10 phút** (VP-3960). TC viết theo code (≤ 10–15 phút), đồng thời ghi nhận trần 1 giờ của doc.
> 3. **MT-3 — Remote View phía POS:** code POS production (cả origin/production và origin/develop) **không có** thành phần Remote View/remote desktop, không lưu "remote credential" (chỉ lưu credential đăng nhập thiết bị, mã hoá). Remote View nếu có là công cụ bên ngoài app → hành vi phía POS cần PO/BE xác nhận.
> 4. **MT-4 — Disconnect phía POS:** spec không mô tả. Code POS: chỉ bị đá ra khi request API nhận 401 và refresh token cũng 401 → `clear_token` → `tokenCleared` → main về `/login`, màn khách về Welcome. Nếu Portal Disconnect chỉ đổi trạng thái mà không thu hồi token thì POS sẽ tự Online lại ở heartbeat kế tiếp (≤ 5 phút).
> 5. **MT-5 — Trigger "Logout":** POS production **không có nút Logout** (phiên chỉ kết thúc qua `tokenCleared`), nên trigger "Device logout" của doc chỉ kiểm được qua thu hồi token.
> 6. **MT-6 — Printer trên Portal:** POS chỉ ghi `device_hardware` khi **serial** của terminal/printer thay đổi (cắm/rút); máy in không trả serial thì không có dòng Printer; trạng thái **Not Installed Driver** trên header POS không có trạng thái tương ứng trên Portal (chỉ Ready / Not connected).
> 7. **MT-7 — Hai trang Device:** Device Management toàn hệ thống (Doc Device Pending: Pending/Active/Inactive, OTP) và trang Device theo merchant (VP-1198) — comment trên VP-1198 còn bàn việc gộp. Cần xác nhận thiết bị Pending/Inactive có xuất hiện ở trang merchant không.
